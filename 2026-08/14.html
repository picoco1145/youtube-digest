잠재고객(Lead) 응답 관리 부실로 발생하던 80%의 노쇼 문제를 해결하기 위해 Rocket New와 Notion SOP를 연동한 AI 자동화 시스템을 구축했습니다. 이 AI는 들어오는 문의를 자동으로 분석 및 점수화하고 답장까지 작성해 주어 20분 만에 구축을 완료하고 2만 달러의 추가 매출을 올렸습니다. 또한 시스템 생성 과정 중 발생한 문제는 Rocket New의 실제 지원 담당자를 통해 즉시 해결할 수 있었습니다.

주요 포인트

  • 높은 잠재고객 획득 비용에도 불구하고 응답 문제로 인해 80%의 높은 노쇼율과 고객 손실이 발생함
  • Rocket New를 이용해 기존 Notion SOP 문서를 연동하고, 한 문장 입력으로 리드 점수화 및 답장 자동화 앱을 생성함
  • AI가 예산, 일정, 예약 여부 등 기준에 대해 확인 질문을 던져 정교한 점수화 로직을 완성함
  • 앱 생성 과정에서 문제가 발생했으나 Rocket New 실제 담당자의 신속한 실시간 지원으로 해결함
  • 서비스 플랜에 따라 이메일, 디스코드 연결 및 유료 플랜의 상담원 직접 지원 기능을 제공함
  • 단 20분 만에 자동화 이메일 응답 시스템 구축을 마치고 이번 달 2만 달러의 추가 수익을 달성함
내 잠재고객 응답 기능에 문제가 있어서 고객 한 명을 잃을 뻔했어요. 우리는 잠재 고객 한 명당 수백 달러를 지불했지만, 그중 80%는 약속 장소에 나타나지 않았습니다 . 그래서 제가 이번 달에 2만 달러를 추가로 벌어들인 방법을 알려드리겠습니다. 저는 Rocket New에 가서 제가 이미 신규 리드 처리 방법에 대한 표준 운영 절차(SOP)를 적어 놓은 Notion 문서를 가리켰습니다 . 그런 다음 저는 한 문장만 입력하면 모든 새로운 문의를 읽고, 전화할 가치가 있는 문의를 점수화하고, 답장을 작성하는 앱을 만들어 줍니다. 그리고 거기서 그치지 않았습니다 . 중간에 멈추더니 실제로 어떤 잠재 고객이 우리에게 연락할 가치가 있는지 물어봤습니다. 예산 문제인가요? 일정 문제인가요, 아니면 이미 예약을 마쳤는지 여부인가요? 제가 답변을 했더니, 단순히 추측하는 것이 아니라 제 답변을 바탕으로 점수가 매겨졌습니다. 그런데 작업 도중에 뭔가 문제가 생겨서 고객이 저를 기다리게 됐어요. 바로 그때 로켓츠 신임팀의 실제 담당자가 나섰습니다. 그들은 문제점을 살펴보고 즉시 해결했습니다. 현재 모든 요금제에서 무료 플랜은 실제 이메일과 디스코드 연결을 제공하고, 유료 플랜은 실제 상담원과의 연결을 지원합니다. 그리고 20분 후, 마치 마법처럼 앞으로 새로 들어오는 모든 잠재 고객에 대한 이메일이 바로 이런 내용으로 제게 도착했습니다. 댓글에 "필요해요"라고 남겨주시면 시스템 설정에 필요한 정확한 안내와 모든 자료를 보내드리겠습니다. rocket.new/build로 이동하세요.

자동화가 브라우저 밖으로 나온 순간

핵심 요약

코덱스 브라우저 에이전트는 API 유무와 상관없이 사람이 브라우저에서 수행하던 클릭 및 입력 작업을 그대로 대신한다. 웹 테스트와 시각적 코드 수정부터 로컬 서버 구동 및 파일 확인까지 하나의 워크플로우로 묶어 처리한다. 이제 자동화는 API 중심 개발을 넘어 AI가 브라우저 화면을 직접 보고 실행하는 단계로 확장되고 있다.

주요 포인트

  • **API 없는 서비스 자동화**: 로그인 상태를 유지한 채 버튼 클릭, 폼 입력, 결과 확인 등 인간의 반복 웹 업무를 자동화함.
  • **실제 사용자 기반 앱 테스트**: AI가 직접 페이지를 탐색하고 입력을 진행하며 화면 깨짐이나 UX 문제를 자동으로 찾아냄.
  • **화면 위 직관적인 코드 수정**: 브라우저상에서 이상이 있는 요소를 직접 표시하고 지시하면 AI가 코드를 고치고 재검증함.
  • **로컬 컴퓨터 작업과의 통합**: 파일 확인, 서버 구동, 브라우저 결과 테스트까지의 일련의 과정을 하나로 연결해 실행함.
  • **자동화 패러다임의 전환**: 단순 API 호출 수준을 벗어나 사람이 브라우저에서 할 수 있는 모든 작업을 AI가 직접 수행함.
이 남자는 브라우저 자동화의 기준을 바꿨습니다. 지금까지 자동화는 API가 있어야 가능하다고 생각했죠. 그런데 코덱스 브라우저 에이전트는 사람이 브라우저에서 하던 클릭, 입력 작업을 그대로 대신합니다. 핵심은 다섯 가지입니다. 첫째, API가 없는 서비스도 자동화할 수 있습니다. 로그인한 브라우저 상태를 유지한 채 버튼을 누르고 홈을 채우고 결과를 확인합니다. 사람이 반복하던 웹 업무가 그대로 워크플로우가 됩니다. 둘째, 앱 테스트를 실제 사용자처럼 돌릴 수 있습니다. 코덱스가 페이지를 열고 버튼을 누르고 입력값을 넣고 화면 깨짐이나 UX 문제를 찾아냅니다. 개발자가 직접 하나씩 클릭하던 시간이 줄어드는 겁니다. 셋째, 애매한 수정은 화면에 바로 표시하면 됩니다. 어디가 겹치는지, 어떤 버튼이 이상한지 브라우저 위에 표시하고 지시하면 코덱스가 코드를 고치고 다시 화면에서 검증합니다. 넷째, 로컬 컴퓨터 작업까지 이어집니다. 파일을 확인하고 서버를 띄우고 브라우저에서 결과를 테스트하는 흐름을 한 번에 묶을 수 있습니다. 정리하면 이제 자동화는 개발자만의 API 작업이 아닙니다. 사람이 브라우저에서 할 수 있는 일이라면 AI가 직접 보고 실행하는 단계로 넘어가고 있습니다. 16분짜리 영상을 정리했습니다. 자료가 궁금하신 분들은 채널 구독 후 링크를 확인해 주세요.
