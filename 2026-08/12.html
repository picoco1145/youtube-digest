주요 포인트

  • 스페이스바를 누르고 원하는 기능(예: 고객 지원 대시보드)을 음성으로 설명하여 개발 요청 가능
  • Cloud Code가 코드베이스를 사전 조사하고 추가 질문을 던지며, 승인받은 실행 계획에 따라서만 코드 수정 시작
  • Opus 5가 기능 구현부터 결과 검증까지 스스로 반복하며 완성도를 높임
  • 개발자의 지시를 수동으로 처리하는 툴이 아닌, 자율적으로 일하는 동료 개발자처럼 동작함
I literally just talked to my code now. I hold the space bar and I say, "Build me a customer support dashboard where users can view tickets, filter by priority, assign them to team members, and make it feel clean and modern." Then Cloud Code will just turn that into a detailed execution plan. It also asks follow-up questions, it'll research my codebase, and only start making changes once I've actually approved the plan. And then Opus 5 will just get to work. It'll start building the features, it'll start verifying its own work, and it'll just keep going and keep iterating until it's all right. And that's what makes it feel way less like AI tool and more like an autonomous teammate. So, try Cloud Code today.
