I Gave an AI Engineer Access to My Whole Business
↗ 유튜브에서 보기

핵심 요약

비즈니스 전체가 담긴 깃허브 저장소에 자율형 AI 엔지니어 데빈(Devin)을 연동해 활용한 사례다. 데빈은 저장소를 스스로 인덱싱해 위키를 구축하고, 브랜드 스타일을 반영한 랜딩 페이지 제작부터 풀 리퀘스트(PR) 생성까지 자율적으로 처리했다.

주요 포인트

  • Cognition의 자율형 AI 엔지니어 데빈(Devin)에게 비즈니스 전체 깃허브 저장소 접근 권한을 부여함
  • 데빈은 터미널, 코드 에디터, 브라우저가 갖춰진 자체 클라우드 환경을 띄워 작업을 수행함
  • 저장소를 분석해 아키텍처 다이어그램, 요약, 소스 코드 링크가 포함된 위키를 자동으로 생성함
  • AI 인증 프로그램 대기자 명단(Waitlist) 페이지 요청 시, 세부 내용과 브랜드 폰트·색상까지 파악해 페이지를 만들고 PR을 오픈함
  • 슬랙(Slack)이나 리니어(Linear)에서 태그해 호출할 수 있으며, 여러 데빈을 병렬로 무제한 동시 실행 가능함
  • 저장소 맥락을 이미 파악하고 있어 매 작업마다 비즈니스 배경을 반복 설명할 필요가 없음
So, this GitHub repo controls my entire business, so I gave Devin access to it. Devin is an autonomous AI engineer from Cognition. You give it a task and it spins up its own cloud machine with a terminal, an editor, and a browser. So, first it indexed the repo and built a wiki out of it. Architecture diagrams, summaries, links back to the original source files, and then I asked for one thing, a waitlist page for our AI certification program. It found the program details, even our fonts and our colors, and then it built the page and it opened a pull request. Now, what's crazy is you can also tag it in Slack or Linear, and you can run unlimited Devins in parallel. So, instead of explaining my business every single time, point Devin at the repo, but it already knows it. So, just comment Devin and I'll send you the full setup.
